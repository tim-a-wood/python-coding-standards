# Agent instructions for this standards repository

Read [STANDARD.md](STANDARD.md) before editing this repository.

Keep the standard short and reference-based. Do not reproduce PEP 8, PEP 257, Scientific Python guidance, or third-party documentation. Add local rules only where engineering tooling genuinely needs an explicit rule.

Keep `templates/AGENTS.md` as a pointer to the canonical public standard at `https://github.com/tim-a-wood/python-coding-standards/blob/main/STANDARD.md`, not as a duplicate policy. Keep `templates/pyproject.toml` minimal and valid.

When modifying this policy, explain the rationale, compatibility impact, and any extra tooling required.
