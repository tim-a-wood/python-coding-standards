# Python engineering coding instructions

Before changing Python code, read and apply the canonical standard:

https://github.com/tim-a-wood/python-coding-standards/blob/main/STANDARD.md

Apply its upstream references, engineering-specific requirements, and precedence rules. If the document cannot be accessed, report the limitation instead of claiming compliance.

Use this project's existing environment and test commands. Where applicable, run `ruff check .`, `ruff format --check .`, and relevant `pytest` tests. Report checks run, failures, omissions, and justified deviations. Avoid unrelated code changes.
